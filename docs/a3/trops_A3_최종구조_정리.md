# TROPS 랜딩 A3 — 최종 구조 정리

> 2026-08-16 확정. v4.0 정본(카피·디자인마스터) + 마무리 정리 1~3번
> 완료를 기준선으로 함. 이 문서는 **구현 지시서가 아니라 결정
> 정리본** — 구현은 별도 진행.

---

## 1. 배경

기존 랜딩(13섹션 정본 vs 15블록 라이브)의 불일치를 라이브 기준으로
동기화(v4.0)한 뒤, 대표가 제기한 "기승전결 불일치·중복·불필요·
결핍" 문제를 구조 개선안 A(한 줄기 서사) → A-2(3탭 카드 유지) →
**A3(+히어로 미니 신호)**로 다듬어 확정함. 진행 중 CTA 라우팅
오류·법률자문 오인 리스크 등을 추가로 점검·반영.

---

## 2. 최종 섹션 순서

```
1  헤더
2  히어로            ← 미니 신호 + CTA 재정비 (§3)
3  스토리(경험담)
4  HOW IT WORKS
5  결과지/근거
6  안심문구           ← 재프레이밍 한 줄 추가 (§5)
7  3탭 카드           ← 스토리 직후에서 이 자리로 이동
8  QnA               ← 14→10문항 (§4)
9  마감 CTA
10 폼
11 기관안내
12 푸터
```

3탭 카드 문구 자체는 그대로 — **이동만** 함.

---

## 3. 히어로

### 미니 신호 (신설)
- 위치: 리드 문단과 CTA 사이
- 내용: 3상품 정식명 나열, 클릭 시 3탭 카드로 앵커 스크롤(페이지
  이동 아님)
- 이름은 §7 네이밍 결정에 따름 — 현재명 유지 시 「수출 사전점검 ·
  바이어 확인 · 기한 관리」

### CTA 아키텍처
- **주 CTA**: `/check`(사전 확인 3문항) — 기존 라이브 그대로,
  변경 없음
- **3탭카드01·중간CTA·HOW하단·푸터**: `/precheck` 직행, 기존 그대로
  유지("서류 이미 보유자"용 정당한 스킵 경로)

---

## 4. QnA — 14 → 10문항

**삭제 대상 4개** (모두 다른 섹션과 내용 중복):
1. 「무엇을 기준으로 비교하나요」 — §5(근거 섹션)와 중복
2. 「어디에 물어볼 수 있나요」 — §11(기관안내 섹션)와 중복
3. 「셀프서브 사전점검이랑 문의하기는 뭐가 달라요」 — CTA
   구조 자체로 이미 구분되므로 불필요
4. 기준 관련 중복 질문 1개(감사 시 D2로 표기된 항목)

**⚠️ 반드시 존속**: 「법률 자문인가요」 — 삭제 대상 아님. 법률자문
오인 리스크(§6) 방어선이라 QnA 축소와 무관하게 유지

---

## 5. 로드맵 두 항목

「확인 항목 대조표」·「거래 운영」 설명을 각 2줄로 축소. 현재는
팔 수 없는(준비중) 상품 설명이 파는 상품 설명보다 긴 상태.

## 6. 법률자문 오인 리스크 — 재프레이밍

### 리스크 진단
- **초보·수출전**: "비교"와 "검토"를 구분 못 해 "법률 검토 받았다"고
  착각할 위험 높음. 결과지의 근거 5필드(관할·법령명·조문·시행일·
  확인일자)가 형식적으로 정교해 보여 착각을 오히려 강화
- **경력·수출후**: 반대로 "그럼 왜 쓰나, 변호사한테 바로 가지"라며
  가치를 낮게 평가할 위험

### 해법 — 재프레이밍
"TROPS 대신 전문가"가 아니라 **"TROPS로 먼저 정리 → 전문가 상담이
더 빠르고 저렴해짐"**으로 재구성. 한 문장으로 두 리스크를 동시에
방어:
- 위치: 안심문구 섹션에 한 줄 추가
- 위치: QnA「법률 자문인가요」 답변 말미에 동일 재프레임 이어붙임
- 최종 문구는 2단계(마케팅팀 원칙) 작업

### 별도 트랙(이번 범위 제외)
기관안내 5곳(관세청·KOTRA·FTA활용지원센터·무역협회·중기부)이 전부
무역지원기관이고 **법률상담처가 0곳**. HOW 03단계("판단이 남는
사안은 어디에 물어보시면 되는지 안내")와 재프레이밍 문구가 결국
안내할 곳이 목록에 없는 공백. 별도 트랙으로 분리, 이번 A3에 미포함.

## 7. 네이밍 — ✅ 최종 결정: 원래 이름 유지

```
수출 사전점검 · 바이어 확인 · 기한 관리   ← 변경 없음
```

**검토 경위**: "바이어 신원 확인"(신원=너무 무거움/법적 인상) →
"바이어 체크"·"기한 체크"(체크=유상 상품 옆에 놓으니 너무 가벼움/
무료스러운 인상) 순으로 대안을 검토했으나 둘 다 기각. 원래 이름
자체가 문제가 아니라, 이름에 명확성을 억지로 욱여넣으려던 접근이
문제였다는 결론.

**명확성은 이름이 아니라 본문 설명이 담당**: 3탭 카드·히어로 미니
신호 어디서든 이름 아래 이미 한 줄 설명(예: "바이어에게 받은 NDA를
올리시면…")이 붙어 있음 — 명확화는 그 설명 문장의 역할.

**등록명 제약(참고용, 이번엔 미적용)**: 「수출 사전점검」은
통신판매업 신고·환불규정(`/refund`)·이용약관에 걸려 있는 등록
상품명이라 원래도 변경이 자유롭지 않았음.

## 8. 제외 항목 (별도 트랙)

| 항목 | 상태 | 비고 |
|---|---|---|
| CEPA 데모 섹션 | 미결 보류 | 8/10 "독립 섹션 복원" 합의가 구현 누락으로 사라짐. 대표가 재결정한 적 없음 — 로드맵 텍스트로만 존재, 재논의 시 별도 진행 |
| `/check` 스킵버튼 정리 | 미결 보류 | 헤더+step-count 삭제가 문구상 유일한 정확 조합이나 doc/s10 설계서 G1 요구사항("모든 화면 상시노출")과 정면 충돌. G1 근거 확인 선행 필요 |
| 기관안내 법률상담처 부재 | 별도 트랙 | §6 참조 |
| 히어로 CTA 문구(「30초 만에 알아보기」) | 2단계 이월 | SLA성 표현 지적됨, 구조 아닌 문구 사안 |
