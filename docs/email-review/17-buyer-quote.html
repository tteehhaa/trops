17. 견적 보내기(바이어에게 · 사용자 이름으로)

예시 값으로 채운 미리보기 — 문안은 앱 운영 코드(trops_a origin/main 79b9b373)의 함수를 그대로 돌려 뽑았습니다.

보내는 때거래의 «보내기 → 견적 보내기» 화면에서 사용자가 기본 문안을 고쳐 «보내기». 같은 내용 두 번 누름은 발송 열쇠로 한 통.
받는 사람바이어 담당자(10명까지) · 참조 = 보낸 사용자 + 추가 참조(5명까지) — 테스트 모드면 테스트 주소 한 곳(참조 없음)
보내는 주소(From)«회사명 담당자명» <contact@theo-ne.com>(보낸 사람 이름 = 장부의 회사명 + 사용자 이름, 80자)
답장 주소(Reply-To)보낸 사용자의 로그인 이메일
머리글 · 첨부첨부 = PI PDF(파일 5MB · 합계 8MB · 10개까지)
테스트 모드운영(Production) 배포 + 테스트 모드 꺼짐일 때만 실제 주소 · 그 밖에는 테스트 주소 한 곳(outboundMailMode)
형식텍스트만(Resend text · html 없음)
공통 템플릿없음 — 문안 함수가 줄을 이어 붙인 글 그대로
들어가는 값
  • 바이어 이름(없으면 «Sir or Madam»)
  • PI 번호
  • 견적 유효기한
  • 사용자 이름 · 회사명(서명)
  • 꼬리 «— 이 메일은 TROPS를 통해 발송되었습니다»
  • 테스트 모드면 제목 «[테스트 · 받는 사람 N명] » + 본문 머리(원래 받는 사람)
코드 위치
  • trops_a/lib/export-case/buyer-mail.ts:24 — 기본 문안 quoteMailDefaults
  • trops_a/app/organizations/[id]/send/quote/page.tsx:39 — 화면(기본 문안을 채움)
  • trops_a/app/organizations/[id]/send/_mail/actions.ts:117 — 보내기
  • trops_a/lib/work/send.ts:52 — sendMailOnce
  • trops_a/lib/notify/outbound-mail.ts:50 — sendOutboundMail(테스트 모드 · 꼬리)
  • trops_a/lib/notify/email-sender.ts:268 — deliverOnBehalf
정리할 때 볼 점(사실만 · 고치지 않았습니다)
  • 기본 문안은 영어인데 제목 · 서명 · 보낸 사람 이름에 장부의 회사명(한글일 수 있음)이 그대로 들어갑니다.
  • 꼬리 문장은 한국어입니다(받는 사람은 해외 바이어).
  • 사용자가 보내기 전에 제목 · 본문을 고칠 수 있어, 실제 나가는 글은 사람마다 다릅니다.
