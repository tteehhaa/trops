05. 가입 확인(Supabase 인증 메일)

Supabase 대시보드 템플릿 — 아래는 Supabase 기본 템플릿 모양입니다(대시보드 값 확인 전).

보내는 때/account/password 에서 가입(supabase.auth.signUp)하면 Supabase 가 보냅니다. 시범 초대 링크로 들어와 가입할 때도 이 메일입니다.
받는 사람가입하는 이메일
보내는 주소(From)대시보드 «SMTP Settings»의 발신 이름 · 주소 — 커스텀 SMTP(Resend) 연결됨(앱 PRD-54 W-64b), 값은 저장소에 없음
답장 주소(Reply-To)대시보드 설정(저장소에 없음)
테스트 모드테스트 모드와 무관
형식HTML(Supabase 템플릿)
공통 템플릿Supabase 대시보드 Authentication → Emails → «Confirm signup». 저장소에 템플릿 파일 · supabase/config.toml 없음. 앱 PRD-54 는 커스텀 SMTP 연결까지만 적고 «이메일 템플릿 문구 개정 안 함(범위 밖)» — 기본값일 가능성이 높지만 확인이 필요합니다.
들어가는 값
  • {{ .ConfirmationURL }} — PKCE 링크, 돌아오는 곳 https://app.trops.kr/auth/callback?next=…
  • 링크 유효시간 = Email OTP Expiration(가입 · 재설정이 같은 값을 씀 · 설계 문서 기준 3600초)
코드 위치
  • trops_a/app/account/password/page.tsx:126 — sb.auth.signUp
  • trops_a/lib/supabase/auth-browser.ts:9 — PKCE 클라이언트
정리할 때 볼 점(사실만 · 고치지 않았습니다)
  • 한국어 서비스인데 기본 템플릿이면 영어(«Confirm your signup»)입니다.
  • 보낸 사람 이름 · 주소가 Resend 앱 메일(TROPS <contact@theo-ne.com>)과 같은지 대시보드에서 확인이 필요합니다.
