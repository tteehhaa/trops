Supabase 붙여 넣기 파일

← 전/후 목록

Authentication → Email Templates의 Confirm signup / Reset password에서 아래 subject 파일을 제목 칸에, HTML 파일 원문을 본문 칸에 붙여 넣습니다. 운영용은 접미사 없는 파일입니다. 아직 대시보드에 적용하지 않았습니다.

  • 05-auth-confirm-signup: 제목 · HTML · 텍스트 참고판
    시험용: 제목 · HTML · 텍스트
  • 06-auth-reset-password: 제목 · HTML · 텍스트 참고판
    시험용: 제목 · HTML · 텍스트

{{ .ConfirmationURL }}는 Supabase가 채웁니다. 예시 주소로 바꾸지 않습니다. 공식 템플릿 문서

시험용 템플릿은 시험 환경에서만 사용합니다. 앱의 SELF15_EMAIL_TEST_MODE 및 HTML 스위치는 Supabase에 적용되지 않습니다. 일반 템플릿에 동적 테스트 판정은 넣지 않았습니다.

텍스트 파일은 같은 내용의 참고판입니다. 대시보드에는 별도의 plain-text 입력 칸이 없으므로 이 파일을 저장해도 text/plain 전송이 설정되지는 않습니다. 실제 인증 메일의 MIME 구성은 Supabase 수신 시험에서 확인해야 합니다.
