03. 시범 참여 초대 메일

예시 값으로 채운 미리보기 — 문안은 앱 운영 코드(trops_a origin/main 79b9b373)의 함수를 그대로 돌려 뽑았습니다.

보내는 때운영 콘솔 «시범 신청»에서 «초대»를 누를 때. 누를 때마다 새 링크가 생기고 옛 링크는 열리지 않습니다. 링크는 14일(PILOT_INVITE_TTL_DAYS).
받는 사람신청자 — 단, 테스트 모드면 운영 테스트 주소(SELF15_TEST_EMAIL) 한 곳
보내는 주소(From)TROPS <contact@theo-ne.com>
답장 주소(Reply-To)없음 — 답장하면 contact@theo-ne.com 로 갑니다
테스트 모드운영(Production) 배포 + 테스트 모드 꺼짐일 때만 실제 주소 · 그 밖에는 테스트 주소 한 곳(outboundMailMode) — 운영은 지금 테스트 모드 켜짐(앱 문서 doc/self15/prod-env-plan.md 기록)
형식텍스트만(Resend text · html 없음)
공통 템플릿없음 — 문안 함수가 줄을 이어 붙인 글 그대로
들어가는 값
  • 회사명
  • 담당자 이름(없으면 «{회사명} 담당자»)
  • 신청 이메일
  • 가입 링크 https://app.trops.kr/pilot/join/{토큰}
  • 만료일(한국 날짜)
  • 테스트 모드면 제목 머리 «[테스트] 받는 사람 1명 · » + 본문 첫 줄
코드 위치
  • trops_a/lib/pilot/mail-copy.ts:49 — 문안 pilotInviteEmail
  • trops_a/lib/pilot/mail.ts:81 — sendPilotInvite
  • trops_a/app/admin/pilot-applications/actions.ts:65 — «초대» 버튼
정리할 때 볼 점(사실만 · 고치지 않았습니다)
  • 초대·가입 시험 때 이 메일은 신청한 주소가 아니라 운영 테스트 주소로 갑니다(테스트 모드가 켜져 있는 동안).
  • «(주)예시정밀을(를)» — 조사를 괄호로 둡니다.
  • «수출 품목 · 기본 거래 조건이 미리 채워집니다» — 랜딩 신청에는 그 값이 없습니다.
