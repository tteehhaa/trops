## 2. 원본 부재 실사 (2026-08-24)

`docs/prd/PRD_landing_v2.1_main_web_page.md` 는 저장소에 **1개뿐**이며 §5 는 **§5-18 에서 끝난다**.

- **§5-19 없음.** 파일 전체에서 `흐름도`·`flow-how` 문자열 0건. 도입부 문구도 alt 텍스트도 정본이 없다.
- **§5-17 「새 원본」 없음.** §5-17 에 실린 상품 ② 캡션은
  「바이어별 계약 조건과 결제 일정, 이행 상태를 한곳에서 관리하실 수 있습니다.」이며,
  이는 `index.html:2270` 에 **이미 라이브인 옛 캡션과 한 글자도 다르지 않다**.
  즉 PRD 가 아직 갱신되지 않았고, 교체할 「새 원본」이 존재하지 않는다.
- **§5-17 영문 정본 없음.** PRD §5 는 전 항목이 국문 전용이다
  (`scripts/check-b3b-gates.js` G8 이 이미 「영문 미반영(원본 부재)」로 기록 중).

→ [원본 규칙]에 따라 T2·T3 는 **문구를 창작하지 않고 건너뛴다**.

## 3. T3 의 두 번째 독립 블로커 — 배치 충돌

지시된 배치는 「상품 3종 **다음**, 근거·확인 기준일 **앞**」이나,
현재 두 섹션의 실제 순서는 그 **반대**다.

| | 국문 `index.html` | 영문 `en.html` |
|---|---|---|
| 근거 (`.basis`) | L1912 | L1796 |
| 상품 3종 (`.cards-sec`) | L2106 | L1973 |

이 순서는 `docs/a3/trops_A3_최종구조_정리.md` §2 가 확정하고
`test/landing-order-s9.test.js` 가 배치표로 못질한 것이다
(헤더→히어로→스토리→HOW→**근거**→안심→**3탭카드**→QnA). 두 섹션 사이에는
안심(`.assure`) 섹션이 끼어 있다. 지시대로 넣으려면 섹션을 재배치해야 하고,
그것은 A3 §2 확정 순서를 뒤집는 별건이다.
