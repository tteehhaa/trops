## Executive Summary

| 관점 | 내용 |
|---|---|
| **Problem** | B2 로 상품 3종은 맞췄지만 **근거·과금·로드맵·서사가 아직 옛 판**입니다. 근거 섹션은 NDA 비교 기준만 말하고, 「무엇이 무료이고 무엇이 유료인가」를 페이지가 어디에서도 답하지 않습니다. |
| **Solution** | §5-12(근거·확인 기준일)·§5-13(무료·유료 신설)·§5-14(WHAT'S NEXT)·§5-15(스토리)·§5-16(중간 CTA)·§5-17(캡션)을 한 글자도 바꾸지 않고 이식하고, FAQ 에 「결과물의 성격」 3문항을 더합니다. 3탭 이미지를 `assets/img/` 고정 파일명 3개(1600×1000 동일 비율)로 갈아 끼웁니다. |
| **Function UX Effect** | 「무엇을 근거로, 언제 기준으로 말하는가」와 「어디까지 무료인가」가 페이지에서 답해집니다. 이미지 교체가 코드 수정 없이 됩니다. |
| **Core Value** | **말의 근거와 값을 밝힙니다.** 가격·결제 표면은 B1·B2 와 동일하게 1줄도 건드리지 않습니다. |

## 4. 위임받은 의사결정

| # | 결정 | 근거 |
|---|---|---|
| 1 | **FAQ 「결과물의 성격」 3문항은 PRD 에 없어 직접 작성** | 저장소 전체를 찾아도 원본이 없습니다. 새 주장을 만들지 않고 **이미 확정된 문구에서만** 끌어 씁니다(§5-12 기준일 · §5-13 과금 · 기존 법적 고지 · §8-1 결정 1 「사전 점검 리포트」). **승인 필요 항목으로 보고합니다.** |
| 2 | 무료·유료 위치 = **상품소개 바로 뒤** + 배경 연쇄 뒤집기 5곳 | 3종의 값을 말하는 블록이라 상품 바로 뒤가 맞습니다. 배경이 완전 교차라 삽입하면 하류가 뒤집힙니다 — `sec-surface` 클래스만 옮기고 문구는 건드리지 않습니다 |
| 3 | 실제 제품 캡처 2장은 **플레이스홀더로 덮지 않고** 1600×1000 으로 리캔버스 | 지시의 조건은 「없거나 다른 이름이면」입니다. 이미지는 있고 이름만 달랐습니다. 진짜 제품 화면을 회색판으로 바꾸는 것은 지시의 목적(깨진 이미지 방지)과 반대입니다. 여백은 원본 가장자리 색으로 채워 액자가 두 겹으로 보이지 않게 했습니다 |
| 4 | `contract-list.jpg` 만 플레이스홀더 | `/procedures` 캡처가 없습니다(B2 이월 TODO) |
| 5 | `.basis` 의 OGL `<figure>` 유지, `.basis-cap` 삭제 | §5-12 의 「문서 기준」이 OGL 을 그대로 인용하므로 그림이 근거를 받칩니다. 캡션은 §5-12 본문과 같은 말이라 중복입니다 |
