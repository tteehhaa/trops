## 2. 지금 구조가 만든 문제

### 2-1. 한 섹션 안에서 톤이 두 번 바뀝니다

`.trust` 다크섹션이 성격이 다른 두 신뢰장치를 겹쳐 지고 있었습니다.

| 블록 | 무엇을 하는가 | 감정 |
|---|---|---|
| 무보 인용문(`.stat-line`) | 「대금 미회수 한 번이면 자금난」 | **경고** — 심박을 올립니다 |
| 영국 OGL·근거 5종·캡처(`.trust-detail`) | 「기준은 우리가 만들지 않습니다」 | **진정** — 심박을 내립니다 |

s10 이 이 어긋남을 **헤어라인 + 큰 여백**(`.trust-detail`)으로 한 번 덮었습니다. 구획선으로
가려야 했다는 것 자체가 **두 블록이 한 섹션에 있으면 안 된다는 신호**였습니다.

### 2-2. 근거가 상품보다 먼저 나와 허공에 떴습니다

「무엇을 근거로 비교하는지 밝힙니다」의 **「비교」가 가리킬 대상**이 그 앞에 없었습니다.
상품소개(탭)가 「공개된 서식과 하나씩 비교해서」라고 말하는 곳인데, 그 문장이 h2 보다
**뒤**에 있었기 때문입니다. 읽는 사람은 「무슨 비교?」를 안은 채 근거 3줄과 캡처를 지나야
했습니다.

### 2-3. 캡처가 상품과 어긋나 있었습니다

`card-shot-reveal-s11` 이 남긴 미결입니다. 바이어확인 탭이 **사전점검 결과화면**
(`c03-result.jpg`)을 빌려 쓰고 있었고(전용 화면을 찍을 수 없었음), 그래서
`landing-order-s9` O4-b 에 예외 목록(`ALLOWED_REUSE`)이 필요했습니다.

## 3. 목표 순서

```
히어로(기) → 경험담+모르시는게당연(승) → 무보 통계 다크(전·경고)
   → 상품소개 탭 3종(전·해결책) → 영국 OGL·근거·캡처(전·근거)
   → 결 CTA(결) → 안심문구 → HOW → 로드맵 → FAQ → 마감CTA → 폼 → 기관안내 → 푸터
```

읽히는 말로: **「이런 일이 있습니다(경고) → 그래서 저희가 이걸 해드립니다(상품) →
그 판단의 기준은 이것입니다(근거) → 눌러 보세요(행동)」**

## 4. 판단이 필요한 것 (지시가 맡긴 것)

### 4-1. 새 근거 섹션의 배경 — **`--surface`**

앞(상품소개 `--bg`)과 뒤(결 CTA `--bg`) 사이입니다.

| 후보 | 판정 |
|---|---|
| `--bg` | ⛔ `bg → bg → bg` 3연속. 경계가 두 곳 사라집니다 |
| `--surface` | ✅ `bg → surface → bg`. 페이지 전체가 **완전 교차**가 됩니다 |

대가가 하나 있습니다 — 「상품소개 → 결 CTA 는 배경을 잇는다」(감정선을 끊지 않으려는
s9 의 의도된 유일한 연속 쌍)가 **소멸합니다.** 지시가 그 사이에 섹션을 넣으라고 했으므로
연속 쌍은 어차피 유지될 수 없고, 그렇다면 3연속보다 완전 교차가 낫습니다.
`landing-order-s9` O7 을 함께 갱신합니다.

### 4-2. h2 문구 — **그대로 둡니다**

지시가 「문맥에 맞는지 확인하고 필요하면 다듬어라」였습니다. 확인 결과 **다듬을 필요가
없습니다.** 오히려 지금 자리가 이 문장이 원래 있어야 할 자리입니다 —
바로 앞 탭이 「공개된 서식과 하나씩 **비교**해서」라고 말하고, 이 h2 가 「무엇을 근거로
**비교**하는지 밝힙니다」로 받습니다. 같은 낱말이 질문과 대답으로 이어집니다.
(확정본 문구 §6 원문이라 임의 변경 대상이 아니기도 합니다.)

### 4-3. 캡처 3장 배분

| 탭/섹션 | 캡처 | 사유 |
|---|---|---|
| 수출 사전점검(탭1) | `c03-result.jpg` | 지시 5. 사전점검의 **정식 결과화면** |
| 바이어 확인(탭2) | `buyer-guard.jpg` **신규** | 지시 5. 전용 화면 확보 |
| 기한 관리(탭3) | `timeline-map.jpg` | 유지(액자만 통일) |
| 근거 섹션 | `c03-result-detail.jpg` | 「확인해볼 질문」이 **참조 서식 조항번호를 그대로 인용**합니다 — 근거 섹션의 3줄을 화면으로 보여주는 컷 |

이 배분의 부수효과: 기본 노출 이미지에 **중복이 0** 이 되어 O4-b 의 `ALLOWED_REUSE`
예외가 필요 없어집니다(s11 보고서 §8 의 남은 과제 하나가 닫힙니다).

### 4-4. 바이어확인 캡처의 실명 — **가상 상호로 치환**

지시가 준 URL 의 거래는 **실재 기업명**(프랑스 소재)을 싣고 있습니다. 그대로 랜딩에 걸면
「제재·수출통제 추가 확인 필요」가 실명 기업에 붙은 그림이 됩니다.
이 저장소의 캡처 규칙은 처음부터 **가상 문서·개인정보 0건**(`c03-result*.jpg` 는
Alpha Trading Co./Beta Sourcing Inc. 가상 NDA)이었으므로, 같은 규칙을 적용해
상호·등록번호·도메인을 가상값으로 치환한 뒤 찍습니다. 캡션이 그 사실을 밝힙니다.
