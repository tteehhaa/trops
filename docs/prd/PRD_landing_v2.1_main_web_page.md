## 1. 배경

앱(`app.trops.kr`)이 앞서 나갔고 랜딩이 못 따라왔습니다. 코드 조사(2026-08-23)로 확인된 격차:

- 앱 메뉴 9개 중 랜딩이 아는 것은 3개
- **증권 관리**가 랜딩에 통째로 없음 (`/policies`, `/profile/insurance` 라이브)
- 랜딩에 **사실과 다른 숫자 2건** — 대조 항목 수(18 vs 엔진 17), 알림 주기(7·1일 vs 코드 30·7·1)
- **무상 문구가 살아 있음** — `en-nda.html:211` 의 「초기 20건 무상」 영문 CTA 노트
- `/check` 분기에 **무료 앱 경로 없음** — 유료 아니면 문의뿐

3주 뒤 진단서 P1이 끝나면 `/precheck`가 파는 것이 **NDA 문서 비교 → 사전 점검 리포트 발급**으로 바뀝니다.

### 5-8. FAQ `[B2]`

```

한 화면에 모아 관리하실 수 있습니다. 거래별로 지금 조치하실 일과 다가오는 기한이
함께 보이므로, 담당자의 기억이나 수기 메모에만 의존하지 않으셔도 됩니다.

어떤 기업에 적합한가요?
수출 계약서와 미수채권 일정을 엑셀이나 달력으로 관리하고 계시거나,
무역보험 가입 후 통지·신고 기한을 담당자가 직접 챙기셔야 하는
중소·중견 수출기업에 적합합니다. 전담 무역관리 인력이 없거나
한 분이 여러 업무를 병행하시는 환경을 염두에 두고 만들었습니다.
```

**이용 조건**
```
계약서 파일이 없어도 이용할 수 있나요?
네, 가능합니다. 수출 품목과 대상 국가만 입력하시면 사전점검을 바로 이용하실 수

직접 입력하시면 됩니다.

무역보험에 가입하지 않은 일반 수출 거래도 관리할 수 있나요?
네, 가능합니다. 일반 수출 계약의 납품 일정과 인코텀즈 조건, 인보이스 결제일
관리만으로도 활용하실 수 있습니다. 이후 무역보험에 가입하시면 증권 정보와
통지 기한을 추가로 연계하시면 됩니다.

어떤 보험 상품을 지원하나요?
한국무역보험공사의 단기수출보험 포괄보험(건별통지·총액통지), 중소중견Plus+,

지원합니다. 지원 상품은 계속 넓혀가고 있습니다.

**기능·운영**
```
구체적으로 어떤 정보를 관리할 수 있나요?
수출 거래별 계약 조건(인코텀즈, 결제 조건)과 인보이스 결제 만기일, 바이어 정보,
미회수 채권 현황, 무역보험 증권 정보와 통지·신고 기한을 한곳에서 관리하실 수 있습니다.

사내 ERP를 쓰고 있는데도 TROPS가 필요한가요?
일반적인 ERP는 회계 처리와 매출·재고 데이터 관리에 중점을 둡니다.
TROPS는 무역 실무 관점에서 계약 조건 이행과 무역보험 통지 기한 준수,
바이어별 채권 만기 추적처럼 일정상 놓치기 쉬운 행정 업무를 정리하는 데
중점을 두고 있습니다.

엑셀로 관리하는 것과 어떤 차이가 있나요?
거래 건수가 많지 않고 담당자가 매일 확인하신다면 엑셀로도 운영하실 수 있습니다.
다만 거래처가 늘고 무역보험 조건이 복잡해지면 입력 누락이나 기한 착오가
생기기 쉽습니다. TROPS는 약관이 정한 기한을 항목으로 세우고 근거 조문을 함께
표기하므로, 무엇을 왜 챙겨야 하는지 확인하실 수 있습니다.

기한은 어떻게 확인하나요?
등록하신 계약과 증권을 기준으로 기한이 지난 건, 기준일 확정이 필요한 건,
다가오는 건을 나누어 화면에서 확인하실 수 있습니다.
