## 1. 최우선 제약 — 무료 접수 경로

**결과: 무변경.** `precheck.html` 의 `.plans` 블록(라디오 2개·`checked`·id 4종)과 이를 읽는

`<head>` 의 meta description 한 줄과 푸터 태그라인 한 줄, 둘뿐입니다.

새 테스트 2건이 이후 개편에서도 이 경로를 막습니다:
- `무료 접수 경로가 살아 있다` — 라디오·`checked`·id 4종·초기 무상 표기·₩0
- `무료 경로를 읽는 JS 가 그대로다` — `plan` 판정식과 자리 복구 코드

### B-5 — 04 와 05 는 합치지 않았다

합치지 않은 이유 3가지는 Plan §4 에 적었습니다(정본 10개 리듬 / 태그라인 소실 /
역할 차이). 대신 **중복으로 읽히던 원인을 없앴습니다**:

1. 두 섹션이 같은 상품을 같은 이름으로 부르게 했습니다(문서 대조 · 기한 관리)
2. 04 h2 아래 `.cards-lead` 한 줄로 05 로 넘깁니다 — 「각각 무엇을 확인해 드리는지는
   아래에서 하나씩 펼쳐 보실 수 있습니다」

읽는 순서가 *무엇을 파는가*(04) → *무엇을 확인해 주는가*(05)로 갈라져, 같은 말의
반복이 아니라 층이 내려가는 구조가 됐습니다.

### 작업 중 발견해 고친 회귀 1건

「준비 중」 배지는 `.card-title` 자리를 쓰고 있었습니다. 지우고 비워 두자:
- 두 카드의 첫 줄 높이가 어긋났고(01 은 상태줄 있음, 02 는 없음)
- **01 에만 「지금 쓸 수 있습니다」가 남아 02 는 아직 못 쓴다는 뜻**이 되어, 방금 지운
  「준비 중」이 암시로 되살아났습니다

→ 02 에 상태줄을 넣어 닫았습니다. 문구는 01 과 다릅니다 — 기한관리는 미리보기까지가
무로그인이고 실제 계약 등록에서 로그인이 걸리므로(§3), 「지금 **둘러보실** 수 있습니다」
/ `PREVIEW AVAILABLE` 가 정확합니다. 실측: 두 카드 본문 상단이 444px 로 일치.

## 3. 영문판 현황 (E-11)

따라서 C-5(메타 NDA 제거)의 영문 대상이 없습니다 — 누락이 아니라 부재입니다.

### en.html 이 국문과 다른 점 (구조 차이, 이번 스코프 밖)

en.html 은 s9 이전 판이라 **05 아코디언 · 경험담 좌우비교 · 「결」 섹션 3종이 없습니다.**
그래서 두 곳이 국문과 정확히 같아질 수 없었습니다:

1. **안심문구 위치** — 국문은 경험담 **뒤**, 영문은 경험담이 없어 `#how` 첫머리.
   D 의 의도(감정 붙기 전에 방어를 먼저 두지 않는다)는 04 카드 뒤로 내려 충족.
2. **기한관리 패널** — 국문은 05 에 패널 1개를 네 트리거가 공유. 영문은 05 가 없어
   카드 안에 자체 패널을 뒀습니다. 선택자 이름을 국문과 같게 둬서 05 이식 시 그대로
   옮겨갈 수 있습니다.
3. **히어로 CTA 단수** — 국문 3단(비교·문의·미리보기), 영문 2단. `[Get notified]` 는
   en.html 에서 사전등록 폼으로 가는 유일한 진입로라 링크는 유지하고 상품명만 정본으로
   맞췄습니다(`deadline management`).

### en.html 에서만 발견된 이름 충돌 (C-3 부수 소득)

`Trade procedure tracking` 이 **04 카드**와 **07 로드맵 02** 두 곳에 쓰이고 있었습니다 —
한 페이지가 서로 다른 두 상품을 같은 이름으로 부르는 상태. 국문은 원래 갈라져 있었고
(「기한 관리」 vs 「거래 운영」) 영문만 겹쳤습니다. 로드맵을 `Trade operations` 로 갈라
국문 대응을 맞췄습니다.
