## 3. Gap · 판단이 필요했던 곳

### G-1. 🔴 B1 의 AC-4(알림 주기 30·7·1)가 **B2 로 소멸했습니다** — 보고 필요

- B1 은 「기한 7일 전과 1일 전에 메일로 알려드립니다」의 **주기**를 코드(30·7·1)에 맞췄습니다.
- B2 의 §5-3 은 그 **약속 자체를 걷어냅니다** — `L1_EMAIL_TOKEN` 미설정으로 메일이 나가지 않으므로(P-3), 주기가 맞든 틀리든 지킬 수 없는 약속입니다. 이번 배치의 AC-4 는 정반대로 「알려드립니다」의 **부재**를 요구합니다.
- **판단**: 두 조건은 같은 문장을 두고 반대 방향을 가리키며, 동시에 만족할 수 없습니다. 더 나중의 결정이자 이번 지시가 「§5-3 을 그대로 쓰라」이므로 **B2 가 이깁니다.** 「30일 전, 7일 전, 1일 전」은 이제 사이트 어디에도 없습니다.
- **처리**: `check-b1-gates.js` G4 를 조용히 지우지 않고, 원래 의도(**「주기를 말한다면 코드와 같은 주기를 말한다」**)로 다시 적었습니다. 약속이 없으면 통과하고, 되살아나면 30·7·1 을 강제합니다.

### G-2. 영문 문면에 확정 원본이 없습니다

PRD §5 는 국문만 확정했는데 B2 는 `en.html` 도 바꿉니다. 영문은 국문의 뜻을 옮긴 것이며 **PRD 승인 대상이 아닙니다.** 국문처럼 「원문 대조」로 지킬 수 없어 회귀 방지 점수를 깎았습니다. 후속으로 §5 에 영문 확정본을 추가하는 것이 맞습니다.
