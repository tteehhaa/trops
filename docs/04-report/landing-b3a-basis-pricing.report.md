## Lessons Learned

**브라우저가 고쳐 주는 실수는 화면으로 못 잡습니다.** 중간 CTA 교체에서 `</div>` 가 하나 남았는데 화면은 멀쩡했고, 빌드의 태그 시퀀스 비교가 잡았습니다 — 국·영문 양쪽에서 같은 실수였습니다. 섹션 교체 시 **여는 태그를 replace 범위에 포함했는지**를 매번 확인해야 하고, 그 검증을 사람 눈에 맡기면 안 됩니다.
