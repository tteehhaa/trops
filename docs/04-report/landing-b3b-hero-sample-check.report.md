이 페이지는 `bg ↔ surface` 완전 교차입니다(`landing-order-s9.test.js` O7 · 연속 쌍 0).
B3-a 는 섹션 **하나**를 끼워 하류 다섯 행의 배경을 통째로 뒤집어야 했습니다.

`test/landing-b3b.test.js` 가 그 상태를 붙듭니다.

**게이트도 은퇴시켜야 합니다.** B2 와 B3-a 는 「B3(-b) 영역 불가침」 게이트를 각각 두었고,
