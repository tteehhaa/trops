## Lessons Learned

**`git ls-files` 는 한글 경로를 따옴표 인용해 내보냅니다.** 첫 게이트 판이 그 문자열로 파일을 열려다 `ENOENT` 로 **조용히 건너뛰었고**, 한글 경로 문서 11개를 통째로 놓쳤습니다(24건으로 보고 → 실제 83건). `-z` 로 고쳤습니다. 이 저장소는 한글 경로 문서가 많으므로, 앞으로 파일 순회 검사를 쓸 때 같은 함정을 먼저 확인해야 합니다. 아울러 **읽기 실패를 `catch { continue }` 로 넘기면 검사가 통과하는 척만 합니다** — 두 검사 모두 명시 실패로 바꿨습니다.
