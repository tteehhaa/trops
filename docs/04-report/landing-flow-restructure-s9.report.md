랜딩이 **두 번의 설계가 통합되지 않은 채** 나란히 얹혀 있던 것을, 흐름 md §1 의 단일
감정선(기-승-전-결) 하나로 다시 짰습니다. 상품소개 두 섹션을 한 섹션으로 합치고,
신뢰증명을 상품보다 앞으로 올리고, 배경 교차를 실제로 보이게 만들었습니다.

## 2. 고친 문제 4가지

| | 문제 | 결과 |
|---|---|---|
| P1 | 상품소개가 두 번 반복 (2층카드 개요 + 아코디언 상세) | 섹션 2 → 1. 한 상품 = 한 카드 = 한 번의 설명 |
| P2 | 신뢰증명이 상품소개보다 **뒤** — 감정선 역전 | 신뢰증명을 상품소개 앞으로. 「확신을 만든 뒤 상품을 보여준다」 복원 |
| P3 | 경험담+안심문구+HOW 가 한 섹션(1592px)에 뭉쳐 감정선이 늘어짐 | 세 섹션으로 분해(726 / 383 / 692). 방법론은 감정선 밖으로 |
| P4 | 배경 교차 ΔL\* 3.65 — 안 보임 | 6.86 으로 1.9배. `--surface` 위 구획선 토큰 신설 |

## 4. 상품소개 통합 방식

**접힌 카드 = 옛 2층카드, 펼친 카드 = 옛 아코디언.**

- 카드 머리(`.feat-btn`) — 생애주기 · 상태줄 · 상품명 · 한 줄 요약 · 불릿 ← 구 04
- 카드 패널(`.feat-panel`) — 설명 · 예시화면 · 안내문 · 실행버튼 ← 구 05

3열 그리드를 1열 세로 목록으로 바꿨습니다(머리가 2요소 → 5요소로 무거워졌고, 패널 안
캡처가 컨테이너 1/3 폭이면 읽히지 않습니다). 이 형태는 en.html 기한관리 카드에 이미
선례가 있었고, 국문만 두 섹션으로 갈라져 있던 것입니다.

### 첫 구현에서 잡아 고친 것

스크린샷 실측에서 세 카드 모두 **머리의 요약이 패널 설명의 첫 문장으로 그대로 반복**되는
것이 보였습니다. 섹션 중복을 없애면서 카드 안에 같은 중복을 남기면 아무것도 고치지 않은
것이라, 층을 다시 갈랐습니다 — 머리 = 무엇을 하는가 / 패널 = 어디까지·무엇을 더.
`test/landing-order-s9.test.js` O4-a 가 이 겹침을 문장 단위로 검사합니다.

또 재배치로 신뢰증명과 상품소개가 이웃이 되면서 **같은 스크린샷이 한 화면 거리에 두 번**
나오게 됐습니다. 두 컷을 역할로 갈랐습니다 — 신뢰증명은 `c03-result.jpg`(무엇을 근거로
비교하는가), 사전점검 카드는 `c03-result-detail.jpg`(무엇을 받는가). 이제 페이지의
모든 이미지가 각각 한 번씩만 나옵니다.

## 5. 색 토큰

```
--surface:          #F1F5F9 → #E6ECF3    (ΔL* 3.65 → 6.86)
--line-on-surface:  #CBD5E1  (신설)
.sec-surface { background: var(--surface); --line: var(--line-on-surface); }
```

`--surface` 를 진하게 한 대가로 `--line`(#E2E8F0)이 그 위에서 ΔL\* 1.38 — 사라집니다.
`.sec-surface` 가 커스텀 프로퍼티 `--line` **자체를** 갈아 끼우므로 하위 규칙
(border-top · rm-row · qitem …)이 손대지 않아도 따라옵니다. 새 값의 대 `--surface` 대비는
8.29 로, `--line` 의 대 `--bg` 대비 8.24 와 거의 같습니다 — 두 배경에서 선 무게가 같습니다.

시각사양서의 「너무 진하면 얼룩져 보인다」 경고는 지켰습니다 — slate-200(8.24) 직전에서
멈췄고, 테스트 O5 가 하한(5.5)과 상한(8.3)을 함께 잡습니다.

## 9. 다음 사람이 밟을 함정 3개

1. **`#` 로 시작하는 HTML 주석은 배포본에 그대로 남습니다** — `html-minifier-terser` 의
   기본 `ignoreCustomComments`(`/^\s*#/`). 주석 하나가 빌드를 멈춰 세웠습니다.
2. **CSS 주석에 `id="..."` 를 큰따옴표째 인용하면 테스트가 오탐합니다** —
   `M`(주석 제거본)은 HTML 주석만 걷고 `<style>` 안 주석은 남깁니다.
3. **트리거 개수를 `M` 으로 세면 안 됩니다** — 같은 이유로 CSS·JS 주석의
   `[data-timeline-open]` 이 섞여, 트리거를 지워도 검사가 통과합니다. `B`(본문만)로 셉니다.
