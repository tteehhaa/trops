## 🔴 정본 §3-1 `--d-ink-*` 값이 구현과 다릅니다 — 정본 쪽 수정 대기

v3 에서 등재한 세 값을 그대로 쓰면 **본문 7역할이 WCAG AA 미달**이 됩니다.
코드는 이름만 정본을 따르고 값은 대비를 지키는 쪽으로 뒀습니다
(`index.html` `:root` 주석에 같은 내용이 있습니다).

| 토큰 | 정본 §3-1 등재값 | 구현값 | 정본값의 `#0F172A` 위 대비 |
|---|---|---|---|
| `--d-ink-primary` | `.72` | `#FFFFFF` | 9.60:1 ✓ (다만 §6 H2 가 흰색에서 내려감) |
| `--d-ink-secondary` | `.50` | `.72` | 5.23:1 ✓ |
| `--d-ink-tertiary` | `.28` | `.50` | **2.50:1 ✗ AA 미달** |

정본은 "값 자체는 변경 없음, 명명만 정식화"로 적었지만 실제로는 한 단계씩 밀렸습니다 —
와이어프레임이 쓰던 4단계(`#FFF` / `.72` / `.50` / 선 `.28`)에서 `#FFFFFF` 가 빠지고
선 알파(`.28`)가 잉크로 올라왔습니다.

**제안**: §3-1 을 잉크 4단계로 늘리고(`#FFFFFF` 복원) `.28` 은 선 전용
(`--d-line`)으로 되돌리십시오. 와이어프레임 C 블록이 §6 H2 를 `#FFFFFF` 로
명시하고 있어 정본 내부끼리도 어긋난 상태입니다.

### 배포 반영 확인은 스크립트로 합니다 (2026-08-11 신설)

```

```

`npm test` 는 **로컬 `dist/`** 를 봅니다 — 「빌드하면 맞게 나온다」까지입니다.
그 `dist` 가 실제로 그 주소에 올라갔는지는 다른 질문이고, 그 사이에는 프리뷰/프로덕션

⚠️ 프리뷰 URL(`*.vercel.app`)은 SSO 보호 뒤에 있어 `curl` 로는 302 가 옵니다
(`ssoProtection: all_except_custom_domains` — 커스텀 도메인만 공개).
**로그인된 브라우저 안에서 same-origin `fetch`** 로 같은 단정을 돌리면 확인됩니다.

⚠️ 프리뷰 `/` 는 로컬 `dist/` 와 해시가 다릅니다 — **Vercel Live 피드백 툴바**가
