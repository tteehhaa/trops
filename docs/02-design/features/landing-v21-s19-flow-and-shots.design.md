## 2. T3 흐름도 — 3-3 반응형 방식 권고 (**철회됨**)

> 🔴 **아래 스크롤 래퍼 권고는 폐기했습니다** 〔2026-08-24 · PRD §5-19 결정〕.
> 이 권고는 **이전 버전 SVG**(1600×480 이 아니라 1600×1000, 조문 번호와 확인 기준일이
> 본문으로 들어간 판) 기준이었습니다. 교체된 SVG 는 낱말 일곱 개뿐이고 조문·기준일
> 표기가 없어 전제가 사라졌습니다. §5-19 가 「가로 스크롤 래퍼를 넣지 않는다」로
> 정했고 구현도 그렇게 나갔습니다 — `viewBox` 비율만 지키며 컨테이너 폭에 맞춥니다.
>
> ⚠️ **다만 실측은 §5-19 의 전제를 절반만 뒷받침합니다** 〔2026-08-24 · Chrome 실측〕.
> | 폭 | SVG 렌더 | 「계약서」 | 「기한」 |
> |---|---|---|---|
> | 1440px | 1104×331 | **12.4px** | **13.8px** |
> | 390px | 342×103 | **3.8px** | **4.3px** |
>
> 데스크톱은 읽힙니다(그림을 `.body-w` 860px 밖으로 빼 12.4px 을 확보했습니다 —
> 안에 두면 9.7px 이었습니다). **390px 은 3.8px 으로 읽히지 않습니다.** 뷰포트가
> 342px 인데 원본이 1600px 이라 축소율이 0.21 이고, 레이아웃으로는 더 못 키웁니다.
> 지시대로 스크롤 래퍼를 넣지 않았으므로 이 상태로 배포했고, 사실만 여기 적어 둡니다.
> 해소하려면 셋 중 하나가 필요합니다 — ① 모바일 전용 세로 배치 SVG,
> ② 640px 미만에서 `flow-how.jpg` 폴백, ③ 스크롤 래퍼 재도입.

### (폐기) 종전 권고

지시된 두 안 중 **인라인 SVG + 가로 스크롤 래퍼**를 권고한다.

- SVG 는 `viewBox="0 0 1600 1000"` 에 `font-size` 15~21px 본문을 담는다.
  390px 폭에 맞춰 축소하면 15px 글자가 실효 3.6px 이 되어 조문 번호가 사라진다.
  이 그림의 존재 이유가 「근거 제3조 ② · 확인 기준일 2026-08-23」을 보여주는 것이므로
  축소는 그림을 무의미하게 만든다.
- jpg 대체안은 모바일에서 **텍스트 선택 불가**가 되어 check 조건 5 와 충돌한다.

권고 구현 (원본 확보 시 적용):

```css
.flow-scroll { overflow-x: auto; -webkit-overflow-scrolling: touch; }
.flow-scroll > svg { display: block; width: 1600px; max-width: none; height: auto; }
@media (min-width: 1024px) { .flow-scroll > svg { width: 100%; } }
```

`.flow-scroll` 에 `tabindex="0"` 과 `role="region"` 을 주어 키보드로도 스크롤되게 한다.
